# Keep It Updated

We've all seen this message:

> **Update available — Restart now?**

And we've probably all clicked:

> **Remind me later**

But updates are one of the most important ways to keep your device secure.

---

## Why do devices need updates?

Software isn't perfect.

Over time, developers discover problems or weaknesses that could be used by criminals to get into a device or steal information.

Security updates **fix those weaknesses**.

Updates can also:

- Fix bugs and problems
- Improve stability
- Add new features
- Improve security

### Think of it like fixing a broken lock

If somebody discovers that a particular type of lock can easily be opened, the manufacturer needs to fix it.

A security update does something similar for your device.

---

## What should I keep updated?

It's not only your computer.

Remember to update:

- **Windows or macOS**
- **Your phone or tablet**
- **Your internet browser** — Chrome, Edge, Firefox, Safari
- **Apps and programs**

Most modern devices can install important updates automatically.

---

## Should I turn automatic updates on?

### Yes, for most people this is the easiest and safest option.

Automatic updates mean you don't have to remember to check for every new security fix yourself.

You might still occasionally be asked to:

> **Restart to finish installing updates**

If possible, don't keep postponing this for weeks or months.

---

## What about Windows 10?

This is particularly important if you have an older computer.

### Regular support for Windows 10 ended on 14 October 2025.

That doesn't mean a Windows 10 computer suddenly stopped working.

It can still:

- Turn on
- Connect to the internet
- Run your programs
- Open your files

**The important difference is security support.**

Without ongoing security updates, newly discovered weaknesses may no longer be fixed through normal Windows 10 support.

:::warning
If your computer is still running Windows 10, don't panic.

It doesn't mean you need to throw it away today.

Check what version you have and what update/support options are available before deciding what to do.
:::

---

## How do I check for Windows updates?

On Windows 11:

**Start → Settings → Windows Update**

You should see whether your computer is up to date or whether updates are waiting to be installed.

### Not sure which Windows you have?

Press:

**Windows key + R**

Type:

`winver`

and press **Enter**.

You'll see which version of Windows your computer is running.

---
### How do I check for updates on a Mac?

Click:

**Apple menu → System Settings → General → Software Update**

Your Mac will check whether macOS updates are available.

You can also check that automatic updates are enabled.

## What about phones and tablets?

Phones need security updates too.

### iPhone / iPad

**Settings → General → Software Update**

### Android

The exact location varies between manufacturers, but usually look under:

**Settings → System → Software update**

or search Settings for **"update"**.

---

## One important rule

### Don't install an "update" from a random pop-up, email or text message.

If you receive a message saying:

> **URGENT! Your device is out of date — click here to update now**

don't use the link.

Instead, go directly to your device's **Settings** and check for updates there.

---

## The simple version

**Keep your device updated.**

**Use automatic updates where possible.**

**Restart when updates need it.**

**Check updates through your device settings — not through unexpected links.**
