# Let's Try to Crack a Password

Which of these passwords do you think would be easiest to guess or crack?

## Have a look

### A
`Password123!`

### B
`Margaret1964`

### C
`Summer2026!`

### D
`BlueHorseRiverLamp`

### E
`T7#mQ9!vL2@p`

---

## What do you think?

Try to put them in order:

**Weakest → Strongest**

There may be more than one thing to think about:

- Is it a common word?
- Does it include a name or year?
- Does it follow a predictable pattern?
- Is it long?
- Is it random?
- Could information about the person help someone guess it?

---

## Let's look at them

### `Password123!`

Very weak.

It uses one of the most common password words, followed by a very common number pattern and symbol.

Adding `!` does not suddenly make a predictable password strong.

---

### `Margaret1964`

Also risky.

A name and a year may be easy to guess, especially if personal information is available online.

Attackers may try combinations of:

- names
- birthdays
- years
- pet names
- places
- family details

---

### `Summer2026!`

It looks quite strong.

It has:

- a capital letter
- numbers
- a symbol

But it follows a very common pattern.

A season + year + symbol is something password-cracking tools can try.

---

### `BlueHorseRiverLamp`

Much better.

It is:

- long
- made from several words
- easier to remember

But it is only strong if the words were chosen unpredictably.

---

### `T7#mQ9!vL2@p`

Very difficult to guess.

It is long and random.

But there is one problem...

### Would you remember it?

This is where password managers can help.

---

## The lesson

A good password is not just about adding:

- a capital letter
- a number
- a symbol

:::tip The three things to remember
A strong password should be:

### Long  
### Unpredictable  
### Unique

You do not need to make every password impossible to type.
:::

---

## A useful trick

One easy approach is to use several unrelated words.

For example:

`River-Cactus-Mirror-Train`

---

## Important

:::warning
Never share your real password during an exercise like this.

We are only using made-up examples.
:::
