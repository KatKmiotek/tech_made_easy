# Password Managers

Most of us now have far too many passwords to remember.

That is where a password manager can help.

A password manager stores passwords for you and can often:

- create strong passwords
- remember them
- fill them in automatically
- sync them between devices
- warn you about reused or weak passwords

---

## You may already be using one

Many people use a password manager without really thinking about it.

For example:

- Apple Passwords / iCloud Keychain
- Google Password Manager
- Microsoft Edge password storage
- browser password managers

You may notice your phone offering:

> Save this password?

or:

> Use a strong password?

That is your password manager helping you.

---

## Why is this useful?

Without a password manager, people often end up doing one of two things:

### Reusing the same password

or

### Creating small variations

For example:

`Garden2025!`

then:

`Garden2026!`

A password manager lets you use a completely different password for every account.

<div className="alert alert--success" role="alert">

**The biggest benefit of a password manager is not convenience.**

It makes it practical to use **unique passwords everywhere**.

</div>

---

## What does a password manager create?

Instead of something easy to remember, it may create a password like:

`k8!Qv2#Lp9@rT4`

You do not need to remember it.

The password manager remembers it for you.
