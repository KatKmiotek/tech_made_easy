# What Do They Know About Me?

A scammer does not always need to "hack" you.

Ask:

> **What information about me could somebody find online without breaking into anything?**

Possible examples:

- full name
- town
- workplace
- birthday
- family members
- pet names
- hobbies
- photographs
- holiday posts
- email address
- phone number

---

# What Information Do Scammers Want?

| Information | Why it can be useful |
|---|---|
| Full name | Makes impersonation believable |
| Email address | Phishing and account login attempts |
| Phone number | Scam calls, messages and account recovery |
| Date of birth | Identity checks |
| Address | Identity fraud and convincing messages |
| Password | Direct account access |
| Reused password | Access to several accounts |
| Security code | Completing a login or payment |
| Bank/card details | Financial fraud |
| Pet names | Password or security-question clues |
| Family names | Family impersonation scams |
| Holiday/location posts | Personal context and targeting |

---

# How Can They Get It?

Information can come from:

- public social media profiles
- things we post ourselves
- fake websites
- phishing forms
- data breaches
- online competitions
- public directories
- compromised accounts
- information bought or shared between criminals
- information given during a phone call

---

# The Harmless Facebook Quiz?

Example:

> **What's your magical Highland name?**  
> First word = name of your first pet  
> Second word = street you grew up on  
> Add your birth month!

It looks harmless.

But questions like these may reveal:

- pet names
- childhood streets
- birthday information
- first school
- mother's maiden name

Some of these can overlap with passwords, password hints or security questions.

> **One answer may seem harmless. The risk grows when several pieces are combined.**

---

# Before Posting

Ask:

> **Who can see this, and does it need to be public?**

Think carefully before posting:

- full birthday
- exact holiday dates
- boarding passes or tickets
- personal documents
- home address
- family details
- answers to online questionnaires
