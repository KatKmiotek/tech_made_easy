# Let’s Check One Together

Tools can help, but the best first step is still:

> **Verify independently.**

## Check Independently First

If a text says:

> "Your bank account has been suspended. Call this number."

Do not use that message to prove itself.

Instead:

1. close the message
2. open the genuine banking app yourself
3. check notifications
4. use contact details from the card, app or official website

> **Independent verification beats detective work.**

## Have I Been Pwned

https://haveibeenpwned.com/

This can show whether an email address appears in known data breaches.

It helps explain why a scammer may know:

- your email address
- an old password
- other information

without having hacked your device today.

## Link Checker

Example:

https://nordvpn.com/link-checker/

A link checker can help inspect a suspicious URL without visiting the page directly.

But remember:

> **A tool saying "safe" is not a guarantee.**

A very new scam site may not have been detected yet.

## Scam Text Checker

Example:

https://nordvpn.com/scam-text-checker/

These tools can analyse suspicious message content.

Before pasting anything into a third-party service:

- remove names
- remove addresses
- remove account numbers
- remove other sensitive personal information

## Reverse Image Search

Tools such as TinEye can sometimes help investigate:

- suspicious profiles
- product photographs
- fake adverts

But reverse image search is another clue — not proof on its own.
